# 佳文和博文的消防车

一个可以玩的 3D 消防车，给 3–5 岁的小朋友。车用 **Blender** 建模（Python 脚本生成），用 **Three.js** 在浏览器里交互。

## 怎么玩

- **线上**：https://wabyking.github.io/fire-truck-toy/ （电脑、平板、手机的浏览器都能直接玩）
- **电脑**：双击 `dist/佳文和博文的消防车.html`（Chrome / Edge），点「出发！」。不需要联网。
- **平板 / 手机**（和电脑连同一个 Wi-Fi）：在本文件夹运行 `node tools/serve.mjs`，然后在平板浏览器里打开它打印出来的地址。

### 点车上的东西
| 点哪里 | 会怎样 |
|---|---|
| 车门（4 扇） | 打开 / 关上，能看到驾驶室和座椅 |
| 侧面卷帘（7 个） | 卷起来，露出工具；再点里面的工具，工具会跳出来转圈，并说出名字：灭火器、水带、头盔、消防斧、路锥、急救箱、手电筒、消防靴、安全绳、消防钩 |
| 水泵面板的彩色阀门 | 转一下，出水口喷水，压力表指针会动 |
| 车头铜铃 | 叮铃铃 |
| 车顶警灯 | 红蓝闪烁 |
| 车尾水带卷盘 | 转起来 |
| 车轮 | 嘀嘀 |
| 驾驶室里的佳文、博文 | 挥手打招呼 |
| 云梯转台 / 支腿 | 升起云梯 / 放下支腿 |

### 大按钮
🚨 警灯 · 📢 警笛 · 📯 喇叭 · 🔔 铃铛 · 🚪 车门 · 🧰 工具箱 · 云梯 · 🦵 支腿 · 💦 按住喷水 · 🔥 去救火

### 开车
- 点地面上任何地方，消防车自己开过去（适合博文）。
- 左下角方向键：⬆ 前进、⬇ 倒车、⬅ ➡ 转弯（适合佳文）。电脑上也可以用方向键 / WASD。
- 开到消防站门口，车库门会自动卷起来。

### 任务
- **救火**：过一会儿某座房子会着火（也可以按 🔥）。点着火的房子，消防车会开过去；到了以后按住 💦，消防车会自己放下支腿、升起云梯、对准火喷水。火灭了会放彩带，得一颗 ⭐。
- **救小猫**：公园大树的树枝上有一只小猫。点小猫，消防车会开到树下、升起云梯；小猫跳上云梯，被送回地面，再得一颗 ⭐。
- 消火栓也可以点：会喷出水柱。

### 电脑快捷键
L 警灯 · N 警笛 · H 喇叭 · B 铃铛 · T 工具箱 · U 云梯 · O 支腿 · 空格 喷水 · F 救火 · C 切换镜头

## 文件
```
blender/build_truck.py    用代码在 Blender 里建整辆消防车（每个会动的部件都有命名的转轴），导出 glb
blender/fire_truck.blend  可以直接用 Blender 打开继续修改的模型（部件没有合并）
assets/truck.glb          导出的模型
voice/lines.json          40 句中文语音提示（edge-tts，zh-CN-XiaoyiNeural）
src/main.js               主程序：镜头、点击、开车、救火、救小猫、按钮
src/truck.js              载入模型，驱动车门、卷帘、警灯、云梯、支腿、阀门、车轮……
src/world.js              小镇：消防站、房子、公园、大树和小猫、消火栓、路灯、云
src/fx.js                 水柱、水花、积水、火焰、烟、蒸汽、彩带
src/audio.js              所有声音（警笛、喇叭、铃铛、发动机、水声……）都是实时合成的
tools/build.mjs           打包成一个 HTML 文件（模型、语音都嵌在里面）
tools/shots.mjs、taptest.mjs、showcase.mjs   自动试玩、截图、点击测试
```

## 重新生成
```sh
# 1) 模型（Blender 4.5，放在 D:/tools）
D:/tools/blender-4.5.15-windows-x64/blender.exe -b --factory-startup --python blender/build_truck.py -- assets/truck.glb
# 2) 打包
npm install
node tools/build.mjs        # -> dist/佳文和博文的消防车.html
```
