# 佳文和博文的消防车

一个可以玩的 3D 消防车，给 3–5 岁的小朋友。车用 **Blender** 建模（Python 脚本生成），用 **Three.js** 在浏览器里交互。

## 怎么玩

- **线上**：https://wabyking.github.io/fire-truck-toy/ （电脑、平板、手机的浏览器都能直接玩）
- **电脑**：双击 `dist/佳文和博文的消防车.html`（Chrome / Edge），点「出发！」。不需要联网。
- **平板 / 手机**（和电脑连同一个 Wi-Fi）：在本文件夹运行 `node tools/serve.mjs`，然后在平板浏览器里打开它打印出来的地址。

### 点车上的东西
| 点哪里 | 会怎样 |
|---|---|
| 车门（4 扇） | 打开 / 关上，能看到驾驶室和座椅 |
| 侧面卷帘（7 个） | 卷起来，露出工具；再点里面的工具，工具会跳出来转圈，并说出名字：灭火器、水带、头盔、消防斧、路锥、急救箱、手电筒、消防靴、安全绳、消防钩 |
| 水泵面板的彩色阀门 | 转一下，出水口喷水，压力表指针会动 |
| 车头铜铃 | 叮铃铃 |
| 车顶警灯 | 红蓝闪烁 |
| 车尾水带卷盘 | 转起来 |
| 车轮 | 嘀嘀 |
| 驾驶室里的佳文、博文 | 挥手打招呼 |
| 云梯转台 / 支腿 | 升起云梯 / 放下支腿 |

## 关卡（第 2 版）
打开后先选关卡。每关有一张任务清单（左上角），做完就过关，按用时得 1–3 颗 ⭐，星星会记在这台设备上；过了一关才解锁下一关。

| 关 | 名字 | 要做的事 |
|---|---|---|
| 1 | 认识消防车 | 打开车门、卷帘，点一件工具，开警灯、敲铃铛 |
| 2 | 出车啦 | 从车库出发，打开警笛，依次开过路上的 3 个光圈，再停回消防站门口的停车框 |
| 3 | 小小火苗 | 开到着火的房子，喷水把火灭掉 |
| 4 | 救小猫 | 小猫困在大树上，用云梯把它接下来 |
| 5 | 加满水 | 水箱快空了：先开到消火栓接水管加满水，再去灭火 |
| 6 | 两处着火 | 两座房子着火，水不太够，中途要自己去加水 |
| 7 | 汽车着火 | 汽车起火是油火，水灭不了，要切换成 🧼 泡沫 |
| 8 | 夜间大救援 | 晚上：先把阳台上的小狗救下来，再灭火 |

还有 **自由玩**：没有任务，随便开、随便喷，可以切换白天 / 黑夜，房子会随机着火。

## 消防车的新本事
- **水箱**：右上角水位表。喷水会用掉水，空了就喷不出来；开到 **消火栓** 旁边点它，会接上水管，自动加满。
- **水 / 泡沫**：💧/🧼 按钮切换。泡沫是白色的，专门扑灭汽车的油火。
- **路上的小汽车**：会在环路上跑。打开 📢 警笛，它们会靠边让路。
- **转向灯、倒车灯、刹车灯**：转弯时转向灯闪，倒车时倒车灯亮还会“嘀嘀”响。
- **云梯救援篮**：云梯顶端有救援篮，篮子始终保持水平，小猫、小狗坐在里面被送下来。
- **镜头**：🎥 在 跟随 / 驾驶室 / 自由 三种视角间切换。
- **白天黑夜**：夜里有星星、月亮、路灯和车灯，警灯、火光会发光。

### 大按钮
🚨 警灯 · 📢 警笛 · 📯 喇叭 · 🔔 铃铛 · 🚪 车门 · 🧰 工具箱 · 云梯 · 🦵 支腿 · 💧/🧼 水或泡沫 · 💦 按住喷水 · 🎥 镜头 · 🔥 去救火 · 🌙 白天黑夜（自由玩）

### 开车
- 点地面上任何地方，消防车自己开过去，会绕着公园走环路，遇到汽车会避让（适合博文）。
- 左下角方向键：⬆ 前进、⬇ 倒车、⬅ ➡ 转弯（适合佳文）。电脑上也可以用方向键 / WASD。
- 开到消防站门口，车库门会自动卷起来。

### 任务（自由玩里也有）
- **救火**：点着火的房子，消防车会开过去；到了以后按住 💦，消防车会自己放下支腿、升起云梯、对准火喷水。
- **救小猫 / 小狗**：点它们，消防车会开过去、升起云梯，把它们接到救援篮里送回地面。

### 电脑快捷键
L 警灯 · N 警笛 · H 喇叭 · B 铃铛 · R 车门 · T 工具箱 · U 云梯 · O 支腿 · G 水/泡沫 · 空格 喷水 · F 救火 · C 切换镜头

## 文件
```
blender/build_truck.py    用代码在 Blender 里建整辆消防车（每个会动的部件都有命名的转轴），导出 glb
blender/fire_truck.blend  可以直接用 Blender 打开继续修改的模型（部件没有合并）
assets/truck.glb          导出的模型
voice/lines.json          79 句中文语音提示（edge-tts，zh-CN-XiaoyiNeural）
src/main.js               主程序：渲染（夜间泛光）、按钮、关卡菜单、过关结算
src/play.js               玩法引擎：开车和寻路、水箱和消火栓、喷水/泡沫、火、救援、镜头、白天黑夜
src/levels.js             8 个关卡的任务和星级
src/traffic.js            环路上的小汽车（听到警笛会靠边让路）
src/truck.js              载入模型，驱动车门、卷帘、警灯、云梯、支腿、阀门、车轮……
src/world.js              小镇：消防站、房子、公园、大树和小猫、阳台小狗、消火栓、路灯、天空（白天/星空）
src/fx.js                 水柱、水花、积水、火焰、烟、蒸汽、彩带
src/audio.js              所有声音（警笛、喇叭、铃铛、发动机、水声……）都是实时合成的
tools/build.mjs           打包成一个 HTML 文件（模型、语音都嵌在里面）
tools/playlevels.mjs      自动把 8 关都玩一遍，报告过关、星级、报错
tools/trace.mjs           逐秒记录某关里消防车的状态（调试用）
tools/shots.mjs、taptest.mjs、showcase.mjs、v2smoke.mjs   截图、点击测试、冒烟测试
```

## 重新生成
```sh
# 1) 模型（Blender 4.5，放在 D:/tools）
D:/tools/blender-4.5.15-windows-x64/blender.exe -b --factory-startup --python blender/build_truck.py -- assets/truck.glb
# 2) 打包
npm install
node tools/build.mjs        # -> dist/佳文和博文的消防车.html 和 docs/index.html（GitHub Pages）
```
